# PetCharm

Аддон для World of Warcraft (retail) и два скрипта для Polished Pet Charm.

## Аддон

- Делает кнопку «Выход» в меню Escape неактивной, чтобы выходить через макрос
  `/cast Revive Battle Pets` + `/logout`.
- Команда `/charm` и кнопка у миникарты ищут ближайшее локальное задание с
  Polished Pet Charm на текущем континенте. Если на континенте таких заданий нет,
  берётся следующее из `PPCQuests.lua`: сначала то же дополнение, потом большая
  награда.
- Подсвечивает Polished Pet Charm в стандартных сумках.
- Сохраняет список собранных питомцев в SavedVariables для `ppc_best_pet.py`.

## Скрипты (Python 3, без зависимостей)

- `ppc_world_quests.py [--region na|eu]` — активные задания с амулетами по зонам
  с данных Wowhead; заодно пишет `PPCQuests.lua` для аддона. Запускать раз в день,
  потом `/reload`.
- `ppc_best_pet.py [--top N] [--lang en|ru]` — самые дорогие питомцы за амулеты,
  которых ещё нет в коллекции, и где их купить.
